Deploy on Vercel (Recommended)

Gym Tracker is optimized for one-click deployment on Vercel:

  1. Push the repository to GitHub.
  2. Connect your GitHub repository to Vercel.
  3. Vercel automatically detects the Vite framework and builds the app.
  4. Your app is live with zero maintenance required!

Self-host with Docker

If you want passkey accounts with multi-device cloud sync on your own VPS:

docker compose up -d --build

Open http://localhost:8080 to create your profile.

Import Training History

Under Settings → Data → Import from another app, you can import data directly from:

  • FitNotes (Android and iOS)
  • Strong & Hevy (CSV exports)
  • Apple Health (body weight XML exports)

Backups

Go to Settings → Export backup (JSON) to download your complete training log, routines, and body weight history into a single backup file.
