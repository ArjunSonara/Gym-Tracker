# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Gym Tracker, please report it directly via email:

📧 **[fightclubsoap1657@gmail.com](mailto:fightclubsoap1657@gmail.com)**

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof of concept.
- Affected components or versions.

We appreciate responsible disclosure and will investigate reports promptly.
