## ⚡ Quick Deployment on Vercel

You can deploy Gym Tracker directly to **Vercel** with zero backend configuration (runs in standalone client-side / local storage mode):

1. Push this repository to your GitHub account.
2. Import the project in [Vercel Dashboard](https://vercel.com).
3. Set Framework Preset to **Vite** (or root directory to `frontend`).
4. Click **Deploy**!

---

## 💻 Local Development

### Prerequisites
- Node.js (v18+)
- npm

### Running the Frontend
```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

### Running with Docker (Full Stack with Passkey Auth)
```bash
docker compose up --build
```
Access at `http://localhost:8080`.

## 🌟 Key Features

- ⚖️ **Body-Weight Tracking** — Interactive charts, progress curve, and target lines.
- 🏋️ **Weekly Routine Planner** — Plan workouts by day over a large exercise database.
- ▶️ **Guided Workouts** — Auto-fills previous weights/reps, integrated rest timer, PR notifications.
- 🔗 **Supersets & Warm-ups** — Create supersets mid-session, track warm-up ramp sets separately.
- ⏱️ **Timed Exercises** — Timed holds (planks, hangs) with live count timer.
- 📈 **Progression Rules** — Linear progression, Greyskull LP, double progression.
- 📱 **Mobile & PWA Ready** — Installable to home screen or built for mobile via Capacitor.
- 📤 **Data Export & Import** — Full backup export/import in JSON.
